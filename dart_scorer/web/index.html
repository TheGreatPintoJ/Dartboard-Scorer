Each row shows what the camera actually reports after a change - cameras routinely accept a value and then ignore or clamp it, so if the reading does not move, that camera does not support that control. Controls appear as sliders where the driver publishes a real range (Linux, via v4l2-ctl) and as boxes otherwise; blank a box to stop setting that control at all. Autofocus and auto-exposure should be off while scoring: both hunt, which pulses the picture and shifts the reference frame the detector compares against.
